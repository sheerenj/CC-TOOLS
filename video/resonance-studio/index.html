Quantise snaps values to discrete steps — motion in increments instead of a smooth slide. Stagger delays each copy in an array so the value travels through it.

Levels are auto-normalised per file, so a quiet voice note and a mastered track start out the same — sensitivity pushes from there. Speech has most of its energy low, so a positive tilt keeps the highs visible. Slow release = the visual breathes; fast release = it snaps.
