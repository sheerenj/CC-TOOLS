The mark is a stage in the chain, not a sticker on top — move it in Chain order. Everything below it still reaches it, so it gets dithered, matrixed, colourised and fed back along with the rest of the image.

Lock its geometry renders it from the parameters here rather than from framing, zoom, pan or anything the randomiser touches — same scale, same spot, every export.

Keep it below the warps stops the randomiser from shuffling it above Space, Lens, Region or Smear, which are the four stages that would move and rescale it. Turn that off if you want it warped with everything else.

Chain order

Drag the ⠿ handle to reorder. Top is the last stage applied, nearest the finished image — the panels below follow the same order. Click a name to jump to its panel.

Region collage
Enable

Cuts the frame into panels; each one re-samples the image at its own offset and scale, or gets slammed to flat colour, or blanked. This is the structure the references have that no amount of filtering reproduces — hard rectangles across organic content, flat fields against dense detail.

Space · 3D
Enable

The mark is drawn by its own stage in the chain — see Mark lock. Put that stage below Space and it keeps its true scale while the space recedes behind it.

Maps the rendered frame onto planes in 3D and flies a camera through them — walls, hanging panels, converging bands. This is the one thing a filter chain cannot fake, and it is what makes the references read as a place rather than a picture. Put it first in the chain so everything after it quantises the composed 3D frame. Advancing the camera by exactly Depth returns the same frame, so it loops.

1 · Lens
Enable

Protect the mark warps everything except the mark's own pixels, so you can drag Lens to the very bottom of the chain — the matrix cells and dither bend optically while the mark holds its exact place. It also releases Lens from the rule that keeps warps above the mark.

Put Lens above Feedback in the chain order and the distortion compounds every iteration — that is the difference between a curved picture and a tunnel you fall into. Negative fisheye gives pincushion.

2 · Feedback
Enable

Hue shift only moves hues that already exist. A grey atom sits on the rotation axis, so it stays grey however far you turn it — raise Hue spread in Logo · Appearance to put colour into the source, or let Colourize below generate it from intensity.

3 · Colourize
Enable
Hold blacks

Maps accumulated light intensity onto the ramp — left of the ramp is darkness, right is the brightest core. Exposure sets how fast light climbs the ramp; Cycles above 1 repeats it for banded spectral rings.

Composited after the chain and never through it, so the rules stay exactly 1px. Panels snap to the grid and to whole pixels — that precision is what separates constructed from generated, and it is the thing every reference frame has that filtering alone cannot produce.

Voronoi cells
Enable

Organic cells with rounded corners and a gap between them. Flat per cell gives each cell one colour sampled at its centre — that is the reference look; Keep the image just cuts the picture into cells.

Contour
Enable

Thin edge lines. Filled shapes alone always read as bulky however good the palette — this is the fine structure the references have everywhere. Lines only throws away the fills and keeps a wireframe.

4 · Smear
Enable

Chunk holds the x coordinate in steps, which is what makes it read as dashes rather than blur. Threshold gates it on brightness so it eats into shapes instead of the whole frame; Re-roll at 0 freezes the pattern.

5 · Dither
Enable

Ramp assigns palette entries by brightness order, so every colour gets used however dim the frame is. Nearest matches RGB, which leaves dark areas on the dark entry and mutes everything.

6 · Matrix
Enable
Non-uniform grid

Rounded bar with Non-uniform grid is the bar-matrix look — wide and narrow columns, rows squeezed to thin bands, each cell a capsule with a gap. Cell size then comes from Columns/Rows rather than the pixel sizes above.

Runs last, so with dither before it each cell lands on one flat palette colour. Unequal cell width and height gives the tall-bar variant. Ring above turns the brighter cells into outlines while the rest stay solid — that mix is what makes the grid read as data rather than halftone.

Chain order is fixed: render → lens → feedback → colourize → smear → dither → matrix. For flat poster colour, drop spread to 0 — that is hard quantisation with no dithering. Dither runs last at output resolution so the grid stays 1:1. Both Amount params are timeline tracks — keyframe them to cut or bleed between looks.

FX is on — SVG export is disabled. Shaders are pixel operations; there's no vector equivalent. Use PNG / ZIP, or switch FX off to export the mark as vector.

Motion lock
Lock logo motion

Every clock becomes a function of the frame number, so frame 40 is the same pose in every preset whatever speed it saved. Each axis turns a whole number of times across the clip, and the pattern and colour clocks are nudged to whole cycles too, so the last frame meets the first. These settings are yours, not the preset's — loading a preset never changes them, so a stack of exports stays in sync. The viewport previews exactly what exports.

Transparent background

Export ALL presets runs the same thing down the whole library, one MP4 per preset. Quick MP4 renders the scene on screen to one MP4, frame-exact at whatever Motion lock says, whatever this preset saved, so every clip exported this way turns at the same rate and they butt-splice in Premiere. The last frame lands on the next clip's frame 0, so there is no repeated frame at the cut. Turns, frames and axis all come from Motion lock, never from the preset — so the viewport is showing you the clip that exports, and every clip shares one rate. Oscillation is off for the run. No alpha — MP4 bakes the background colour; use ZIP if you need transparency.

ZIP is frame-exact and keeps alpha. MP4 records in real time (MP4 on Safari · WebM on Chrome/Firefox). Loop MP4 solves for the shortest seamless loop of the active motion.
